# Eminence’26 – College Fest Website

Eminence’26 is the official event website created for Sri Indu College of Engineering and Technology.
The project combines a modern animated hero section with a clean and responsive UI, while keeping
the original design intact.

---

## ✨ Features

• Animated hero section with multiple scenes  
• Smooth scene transitions (auto + manual navigation)  
• Timeline and progress indicators  
• Responsive design for desktop and mobile  
• Explore Events button integrated inside hero section  
• Clean UI without altering original layout  
• JavaScript-based interactivity  
• Firebase-ready architecture for dynamic features  

---

## 🛠 Technologies Used

• HTML5  
• CSS3  
• JavaScript (Vanilla JS)  
• Firebase (Authentication / Database – optional & extendable)

## 🎬 Hero Section

The hero section contains:
• Scene 1 – College introduction  
• Scene 2 – Innovation theme  
• Scene 3 – Event overview (Day 1, Day 2, Day 3)  

Navigation is supported via:
• Auto-play  
• Progress dots  
• Timeline markers  
• Keyboard arrows  
• Touch swipe (mobile)

The "Explore Events" button is positioned at the **bottom of the hero section**
and smoothly scrolls users to the Events section.

## 🔥 Firebase Setup (Optional)

1. Create a Firebase project  
2. Enable required services (Auth / Firestore / Realtime DB)  
3. Copy Firebase config into `firebaseConfig.js`  
4. Initialize Firebase inside `app.js`  
5. Connect forms or registrations as needed
